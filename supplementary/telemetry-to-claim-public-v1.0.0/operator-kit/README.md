# Operator kit

Use this kit to test one proposed operational statement before it is allowed to
inform a dashboard headline, autonomy decision, research finding, safety claim,
or public assertion.

## Contents

1. [Telemetry-to-Claim Gate](TELEMETRY-TO-CLAIM-GATE.md) — the analytical framework, gate questions, data-treatment actions, and terminal claim dispositions.
2. [Candidate-claim worksheet](CLAIM-WORKSHEET.md) — a blank, copyable form for one claim.
3. [Worked examples](WORKED-EXAMPLES.md) — three transformations from this study plus one synthetic example.

## Minimal use

1. Write the sentence you want to claim.
2. Complete its metric, analytical unit, construct, population, window, denominator, and interpretation.
3. Check producer, schema, coverage, contamination, linkage, detector validity, sensitivity, and outcome evidence.
4. Record data treatment separately from meaning.
5. End with exactly one disposition: retain, narrow, relabel, withhold, or not identifiable from available telemetry.

The kit governs the interpretation and claim that telemetry is allowed to
support. It does not select an operational action, and it does not certify that
an agent system is safe, reliable, productive, or successful. Action still
requires a separate decision process that accounts for costs, values,
reversibility, uncertainty tolerance, and intended use.
