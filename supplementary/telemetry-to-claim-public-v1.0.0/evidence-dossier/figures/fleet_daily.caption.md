**Daily summed active hours across the fleet, with telemetry stream onsets.** TRUSTED files
(n=36,502), day bins, 2026-04-25..2026-07-23. Binning limitation: a session's ENTIRE
active time is attributed to its start day, so multi-day sessions concentrate hours there
(the 2026-04-25 value of ~89 h comes from 3 marathon files starting that day) —
day values are start-day attribution, not work-done-that-day. Dotted lines mark when each reliability stream
began logging — the reliability signals cover only a fraction of the activity window
(hermeneutic-gate: ~37 hours). Uncertainty/missingness: days with zero recorded activity are
shown as zero but hook outages are indistinguishable from true quiet (silence is evidence of
nothing); no imputation. Source: data/derived/fleet_daily.csv.
